# Delegate Governance to DSH

PTC Plus treats `danger-full-access` as its first-class experience and keeps native ambient effects available there, classifying non-replayable state as `volatile`. It does not implement a second cross-platform sandbox or permission system. Other profiles retain only the tool capabilities supplied by the current DSH request; unavailable tool operations fail explicitly. A narrower tool view does not make the worker an ambient Node sandbox. DSH owns tool authority and policy, while process and operating-system confinement own direct Node access.
